# Entrega de Atlante

Este paquete permite presentar y probar Atlante, una herramienta para **asesorías que gestionan ayudas, subvenciones y licitaciones de sus clientes**.

| Archivo | Para qué sirve |
| --- | --- |
| `01-Memoria-del-proyecto.md` | Problema, propuesta, funcionamiento, tecnología, resultados y límites reales. |
| `02-Guion-de-demostracion.md` | Recorrido para el jurado y guion sugerido para el vídeo que grabarás tú. |
| `03-GitHub-paso-a-paso.md` | Publicación del código desde Windows, explicada desde cero. |
| `../public/50-clientes-ficticios.csv` | Cartera ficticia actual de 50 clientes, lista para importar. |

La aplicación: https://atlante-ayudas-canarias.sturdypearl6.chatgpt.site/

Antes de entregar, comprueba el acceso desde otra cuenta de ChatGPT y graba el vídeo. Si el hackathon facilita una plantilla o rúbrica específica, adapta estos documentos a ella.
